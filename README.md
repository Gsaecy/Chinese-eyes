# 🇨🇳 扩展选择助手 — 看透外文，一目了然

VS Code 扩展市场的智能翻译与选择助手。浏览 VS Code 扩展市场，自动将详情翻译为中文，AI 智能总结扩展功能、收费方式与使用指南。

> 🌟 **版本 0.4.0** — 详情完整翻译（长文档整篇 LLM 结构化翻译）+ 翻译保持原文布局 + 免费优先/受限才用 API

---

## ✨ 核心功能

| 功能 | 说明 |
|------|------|
| 🔍 **扩展搜索** | 浏览 VS Code 扩展市场，搜索自动按相关性排序，支持多词关键词与热度、评分、更新时间排序 |
| 🌐 **简介翻译** | 自动将扩展标题和描述翻译为中文；翻译默认走免费在线翻译（有道/Google），受次数/字数限制时自动改用 API |
| 📖 **README 翻译** | 打开扩展详情自动翻译完整 README 并直接显示中文（含 CDN 自动降级） |
| 🧠 **AI 智能总结** | 使用 DeepSeek / OpenAI 兼容 API 自动总结扩展功能、收费模式和使用指南（API 默认专用于 AI 总结） |
| 📊 **安装数据** | 显示扩展安装次数、评分和评价数量，辅助决策 |
| 🗂️ **翻译面板** | 独立翻译面板，粘贴原文即可翻译并生成摘要（免费在线翻译无需配置） |
| 🎯 **精确搜索** | 输入 `publisher.extension` 格式（如 `ms-python.python`）可精确按 ID 搜索 |
| ⚡ **Agent 预设** | 设置中选择 DeepSeek / OpenAI / 阿里云 / Kimi / 智谱等预设，地址和模型自动填充，只需填 API Key |

## 🚀 快速开始

### 1. 安装
在 VS Code 扩展市场搜索 **扩展选择助手** 或 **ext-trans-picker**。

### 2. 配置（可选）
- 默认使用**本地词典**（离线可用，无需 API Key）
- 如需 **AI 总结** 功能，推荐配置 DeepSeek：
  ```
  设置 → 选择 DeepSeek → 填入 API Key → 保存
  ```
- 也支持 OpenAI 兼容协议（阿里云 DashScope、Moonshot、Together 等）

### 3. 使用
- 点击活动栏 🧿 图标打开扩展列表面板
- 搜索扩展，点击「详情」查看翻译后的 README
- 点击「AI 总结」获取智能分析
- 点击标题栏 📝 图标打开翻译面板

## 🌐 更新日志

### 0.4.0 (2026-09-05)
- 🐛 **详情完整翻译**：短文档免费一次翻译；长文档/免费受限改为整篇 LLM 结构化翻译，彻底消除逐块请求限流导致的中英混排
- 🛟 **兑底简化**：LLM 失败后免费整篇再试一次，仍失败则本地词典整篇翻译并明确提示

### 0.3.9 (2026-09-05)
- 📐 **翻译保持原文布局**：Markdown 结构化翻译——代码块/表格/HTML 原样保留，标题/列表/引用前缀剥离后只翻译文本再回填；HTML 文档只翻译文本节点，标签与属性不变
- ⚡ **翻译策略固化**：翻译默认走免费在线翻译（有道/Google）；受次数/字数限制（约 5400 字）才自动改用 API；API 默认专用于 AI 总结
- 🚀 **详情自动翻译**：打开扩展详情自动翻译 README 并直接显示中文（autoTranslateReadme 默认开启）
- 🇨🇳 **中文原文识别**：原文已是中文时直接提示「无需翻译」，不再发起无意义请求

### 0.3.8 (2026-09-04)
- 🔒 **API Key 安全升级**：真实密钥存入系统密钥库（SecretStorage），VS Code 设置中只显示黑点掩码；在设置里直接粘贴新密钥即可更换；老版本明文自动迁移
- 🟢 **设置状态条三色分级**：绿=全部正常，橘=API 正常但模型等次要问题，红=API 错误/过期/未设置等影响功能的错误
